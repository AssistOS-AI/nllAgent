# Scientific report consistency agent

Train an nllAgent that audits internal clinical-research reports for cross-section consistency. The agent must compare
numeric efficacy claims only when metric, estimand, baseline, population, aggregation, time horizon, and unit are
semantically compatible. It must distinguish genuine numeric conflict from a different analysis question, preserve
uncertainty and contradictory source claims, and attach every assessment to exact source spans.

Use the core SDK query, normalization, constraint, and decision providers before considering custom JavaScript. The
trained theory must include executable OntologyJS, RuleAnalysis, CircuitArchitecturePlan, a MaterializationProfile,
CircuitJS, tests, benchmarks, and a mutation check. Analysis tasks must create LongTextJS only in their isolated task
folder and must not modify the trained theory.
