OntologyJS: the executable business vocabulary

OntologyJS says which business facts can be expressed and how they are typed. It does not decide whether those facts satisfy a policy.

Retention ontology from the evaluation

The privacy agent needs controllers, personal-data categories, policy scopes, retention declarations, exception evidence, and coverage evidence. The generated module uses actual constructors and role constraints:

const O = ontology('privacy.retention.eval@1', extendsOntology(core));

export const DataController = O.entity('DataController', requires(retentionName));
export const PersonalDataCategory = O.entity('PersonalDataCategory', requires(retentionName));
export const PolicyScope = O.entity('PolicyScope', requires(retentionName));

export const actor = O.role(
  'retentionActor', from(O.Event), to(DataController), exactlyOne()
);
export const category = O.role(
  'dataCategory', from(O.Event), to(PersonalDataCategory), exactlyOne()
);
export const durationYears = O.role(
  'durationYears', from(O.Event), to(O.Value), exactlyOne()
);

export const RetentionDeclaration = O.event(
  'RetentionDeclaration',
  requires(recordId), requires(actor), requires(category),
  requires(durationYears), requires(assessmentScope), requires(sourceAnchor)
);

export default O.seal();

This is executable JavaScript. RetentionDeclaration(...) validates roles and returns an opaque Term for ground arguments. With a typed circuit variable, the same constructor returns a Pattern. There is no generated object schema between author and runtime.

Derived concept identity such as RetentionAssessmentMaterializing that assessment from source — forbidden

Identity is not a name match

A mention of “Northstar” and a legal entity are separate. LongTextJS anchors the mention and records an identity candidate. Source entities normally use explicit stable identities. Pure derived values may use structural identity when the concept declares it. Qualified concept and role identities participate in structural equality, preventing two ontologies with similarly named roles from colliding.

Local behavior boundary

A duration value type may reject negative years or normalize months to a canonical quantity. A behavior must not inspect a document, decide that an audit purpose is a legal obligation, or accept an exception. The architecture experiment demonstrates why contextual rule behavior in a constructor is invisible to circuit planning and trace.

Failure example

If Codex tries to connect a Person to the durationYears role, construction fails immediately. Broadening the target to Entity only to make that program load is an ontology defect, not a repair. The task should instead emit a typed gap or the ontology should be deliberately retrained.
