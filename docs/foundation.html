Shared baseline · explicit limits · optional alternate worlds

What every agent checks before domain rules

foundation-core@1.1.0 supplies a small ontology and five elementary consistency circuits without asking each agent to relearn them. It covers explicit state and time, exact decimal arithmetic, bounded quantities, a small type vocabulary, and literal emotion attribution. This page defines the exact language boundary and shows the result; it does not promise unrestricted common-sense understanding.

The useful mental model

flowchart LR
  S[Source sentences] --> O[Typed foundation observations]
  O --> C[Five verifier-dominated circuits]
  C --> F[Replay-verified potential inconsistency]
  K[Optional sourced knowledge pack
future extension] -.-> C

Source assertions remain separate from judgment. The ontology names reusable data shapes. The materializer records what the source explicitly says. The circuits compare those records under stable logical principles. None of these steps silently turns a sentence into a verified fact about the outside world.

The recognized copulas are is, are, was, and were. Temporal forms also accept occurred, present tense, and “took/takes place.” The exclusive registry is currently alive/dead, open/closed, present/absent, and on/off. The built-in classes are person, animal, sentient agent, inanimate object, physical object, event, and place. The complete quantity and unit vocabulary is carried in the versioned pack descriptor. Exact wording keeps this baseline testable.

The circuit compares conflicting exact quantities only when their unit tokens are already equal; it performs no conversion. Emotion labels are source words, not a built-in valence taxonomy. The baseline compares the same normalized label and polarity but does not declare different emotions mutually exclusive.

Run mathematics, physics, and emotion checks together

node bin/nllagent.mjs run \
  --agent editorial-demo \
  --input data/editorial-demo/examples/foundation/math-physics-emotion.md \
  --output /tmp/foundation-report.md \
  --translator none

The example needs no agent-specific rules for these subjects. Its CNL audit reports four accepted foundation findings:

FOUNDATION-MATH-001       2 times 3 equals 7; exact replay gives 6
FOUNDATION-PHYSICS-001    mass -2 kg is below the documented lower bound
FOUNDATION-EMOTION-001    Alice both feels and does not feel afraid at noon
FOUNDATION-PSYCHOLOGY-001 the statue is typed inanimate and literally feels lonely

All four: severity warning · guarantee mechanically-certified · verifier accept

“Mechanically certified” applies to the parse, bounded invariant, source anchors, and witness replay. It does not certify that Alice or the statue exists, diagnose an emotion, or settle whether the last sentence is figurative.

What is intentionally not automatic

The pack does not resolve pronouns or aliases, infer actions, infer emotion from behavior, diagnose people, understand figurative language, decide reported speech, identify fictional versus real entities, convert units, or establish that two untimed assertions describe the same moment. It deliberately allows mixed emotions such as happiness and sadness because they are not logical opposites. Findings remain warnings with these limits.

Current presidents, borders, prices, laws, social conventions, demographic claims, and similar knowledge do not belong in universal code. They change or depend on date, jurisdiction, source, and perspective. The intended extension is a named, dated KnowledgePack with evidence and an effective interval. That loader is not implemented yet, so no current-world fact is claimed by the base package.

Where richer meaning belongs

A domain release can demand reusable observations for people, actions, obligations, richer measurements, emotions, or narrative events. An approved deterministic or model-assisted producer then adds those observations with exact anchors, status, alternatives, provenance, and honest coverage. Query-first tables, direct graphs, and specialized operators can consume the same types. The foundation is the shared floor, not a ceiling on domain mathematics or semantics.

Alternative-world mode

nllagent run ... --foundation off
nllagent benchmark ... --foundation off
nllagent plan ... --foundation off

The selection is stored in the run and printed in its report. Turning it off removes only foundation material and circuits; it does not change the immutable agent release. A future replacement pack will require an equally explicit name and digest.

How to review a foundation finding

Check the two source quotes or the ordered cycle, then inspect its time, world, and identity assumptions. The certificate proves that the controlled observations and witness replayed against the immutable source. If the warning is inappropriate, improve the text, choose an alternate world, or propose a versioned parser/ontology change with a close-negative benchmark. Do not weaken the verifier to suppress one example.
