LongTextJS: what this document says

LongTextJS is a source-grounded program for one revision. Codex can organize it with normal JavaScript, but the program may publish only typed ground observations, claims, contexts, alternatives, coverage, and gaps.

A real task materialization

For a policy sentence declaring a ten-year retention period, the task materializer constructs the same ontology term the retention circuit will query and wraps it in an explicit claim:

const anchor = span(source, start, end);
const declaration = RetentionDeclaration(
  identifiedAs(`retention-declaration:${anchor.id}`),
  recordId('CUSTOMER-PROFILE'),
  actor(controller),
  category(customerProfileData),
  durationYears(10),
  assessmentScope(retentionPolicyScope),
  sourceAnchor(anchor)
);

return semanticUnit(
  'retention-customer-profile',
  claim(declaration, explicit(), groundedAt(anchor))
);

The source phrase is evidence for a declaration. It is not evidence that the policy violates authority until CircuitJS compares duration, applicability, exception evidence, and coverage.

Exact Unicode anchors

Spans are half-open Unicode code-point intervals. The substring at [start,end) must match the pinned source revision. Byte offsets and JavaScript UTF-16 indexes are not accepted substitutes. The native source tool reports outline and exact excerpts so a coding role need not count a long document manually.

node tools/nll.mjs source outline agentsEval/privacy-retention/input/customer-policy.md
node tools/nll.mjs source span agentsEval/privacy-retention/input/customer-policy.md 812 934

Claims, identity, and scope

An event is propositional content; a Claim says that the document or a speaker asserts it with an epistemic status. A textual Mention is not automatically an Entity. Reported speech, negation, permissions, obligations, examples, and counterfactuals remain in structural contexts.

“The operator did not confirm that Ana opened the gate” is a negated confirmation whose proposition contains an opening. It is not a negative Open fact. Likewise, two uses of “it” can remain incompatible identity alternatives instead of selecting the higher-confidence guess.

Coverage is earned

Coverage is a positive statement about the materialization procedure. Reviewing a complete exception register may close LegalObligation in that register's scope. Reading a policy that refers to unavailable appendices does not. A literal word search does not close a semantic concept. Open coverage keeps absence UNKNOWN.

Task program capsule

export default function materialize({ source, program, api, ontology, vocabulary }) {
  // local functions, arrays, maps, loops, and conditions are allowed
  // imports, environment, network, subprocesses, findings, and new concepts are not
  return program('customer-policy@r1', source, ...semanticUnits);
}

The host supplies only the selected build's vocabulary. A malformed program, wrong type, invalid span, or forbidden import fails before deterministic execution. A relevant unrepresentable phrase produces a gap and may block one circuit without corrupting other observations.
