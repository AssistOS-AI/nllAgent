The document side

LongTextJS is a program of this source

LongTextJS turns one immutable document revision into an addressable world that CircuitJS can consume. It preserves what the source says, which interpretations were materialized, how they were produced, and what remains unknown. It does not decide whether a rule was violated.

What is compiled

For the current production path, the input is Markdown. The compiler does not reduce it to a summary or an embedding. It preserves canonical text, structure, global Unicode positions, block identities, channels, and exact quotations. It then adds typed observations required by the selected release.

flowchart TB
  STRUCT[Markdown source + exact anchors] --> OBS[Structural observations]
  OBS --> SEM[Demanded semantic observations]
  SEM --> LIMIT[Coverage + capabilities + gaps]
  LIMIT --> LTX[Canonical LongTextJS JSON]

Compilation adds meaning without replacing source. Deterministic structure is established first. Semantic producers add only typed candidates requested by the theory. Coverage and gaps travel with the resulting program.

The shape emitted today

src/longtext/compiler.mjs emits a LongTextProgram using dialect longtextjs-json@1. A normal program contains one source package, view:whole, the run task, blocks and anchors, structural scopes, observations, capabilities, coverage records, gaps, and diagnostics. This shortened example follows the actual output shape:

{
  "kind": "LongTextProgram",
  "dialect": "longtextjs-json@1",
  "id": "longtext:editorial-demo:input",
  "source": {
    "id": "source:input",
    "revision": "sha256:…",
    "mediaType": "text/markdown",
    "language": "en",

Source, anchor, observation

ObjectWhat it assertsWhat it does not assert
Source packageThese are the canonical bytes/text, revision, language, structure, and channels analyzed.That any interpretation of the text is correct.
AnchorThis exact quote occupies this half-open Unicode code-point range in this block and revision.That the quote has a particular semantic role.
ObservationA named producer interpreted or extracted this anchored source as a nominal versioned type.That a rule has been satisfied or violated.

This separation is why an invented model quotation cannot become evidence. Model output names an exact quote inside one source block. The materializer locates that quote again, computes the global anchor, validates the payload, and only then inserts a proposed observation. Repeated equal quotations are assigned to successive occurrences rather than collapsed onto the first match.

Status preserves how something became known

A deterministic paragraph observation is extracted. A model-identified object event is normally proposed. A search branch may add an assumed object. A circuit consequence is derived. A checker may mark one exact property certified. Human confirmation has its own status. Confidence can rank alternatives, but cannot silently change any of these categories.

This matters downstream. A deterministic state replay over model-proposed events can verify that the replay follows the released transition policy; it cannot retroactively prove that each event was semantically classified with mechanical certainty.

LongTextJS is selective, not total

The runtime first compiles structure and then loads the release’s circuits. Their input ports determine the set of observation types to materialize. A lexical circuit may need only document.paragraph@1. A continuity circuit may additionally need object events, identity, order, modality, and an intervening-scope search. nllAgent does not attempt to formalize every possible fact in every document.

Semantic requests go through extraction profiles and the backend-neutral translation gateway. Configured AchillesAgentLib is preferred; the current Coding Agent reference adapter is the fallback. Both return schema-bound candidates to the same materializer. Neither backend constructs the source package, changes anchors, declares coverage unilaterally, or edits CircuitJS. See Compilation and translation.

Coverage and gaps are part of the program

Coverage records name the source revision, channel, scope, observation types, producer, method, exclusions, failures, and completeness mode. A complete structural scan can support “the phrase does not occur in any narrative paragraph in this view.” Top-k semantic retrieval cannot support “no notification exists anywhere.”

A gap is not a negative observation. It may identify an unavailable producer, invalid model output, unknown structure, unresolved identity, missing operational context, unsupported language, or insufficient materialization. The compatibility gate consumes these records before CircuitJS is allowed to make a claim that depends on them.
