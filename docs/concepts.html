Concepts and epistemic boundaries

This page is a lookup guide for the distinctions that prevent fluent output from hiding uncertain computation.

Term
A ground ontology constructor application with concept, typed roles, identity, context, and provenance.
Pattern
The same constructor structure containing typed variables.
Claim
A proposition attributed to source or producer with epistemic status and evidence.
Binding
An immutable mapping from query variables to compatible terms.
Coverage
A scoped statement about completeness; it is required for absence.
Gap
An explicit inability to represent, materialize, resolve, or cover relevant meaning.
Circuit template
A reusable hierarchical computation definition.
Circuit instance
A template bound to concrete terms and an interpretation context.
Macro-node
A normal JavaScript algorithm with typed semantic inputs, outputs, effects, and trace.
Assurance
Mechanical, cross-checked, model-assisted, heuristic, or unverified support for one result.

Three different state systems

SystemExamples
Predicate logicTRUE, FALSE, UNKNOWN, CONFLICT.
Rule resultVIOLATED, ACCEPTED_EXCEPTION, BLOCKED_ONTOLOGY.
Node lifecycleREADY, RUNNING, COMMITTED, FAILED.

Conflating these is a category error: a node may commit an UNKNOWN rule result successfully.
