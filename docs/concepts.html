Concepts that preserve semantic honesty

These terms are deliberately distinct. Most serious natural-language analysis bugs collapse two of them.

Agent build
An immutable accepted RulePack, ontology, profile, circuits, SDK/provider pins, tests, benchmarks, and generated context.
Task
One source and target pinned to one build, with task-local LongTextJS, result, trace, and report.
Term
A ground ontology constructor application with qualified concept, typed roles, identity, context, and provenance.
Pattern
The same ontological structure with typed variables, used by CircuitJS queries.
Claim
Propositional content attributed to source or speaker with context, epistemic status, and evidence.
Mention
An anchored textual occurrence; it is not automatically the entity to which it may refer.
Coverage
A positive completeness assertion for one concept, exact scope, and evidence policy; required for final absence.
Gap
An explicit ontology, identity, temporal, materialization, or coverage limit.
CircuitModel
The reusable typed computation constructed by a CircuitJS module.
CircuitInstance
A model bound to one snapshot, interpretation, and concrete input/bindings.
Execution graph
Concrete nodes and immutable ValueRefs created for one run; not the authoring format.
Method
A local algorithm family such as query, decision, constraints, relation closure, rewrite, proof, or synthesis.
Interpreter
A mode—concrete, abstract, symbolic, concolic, proof, synthesis—for evaluating supported parts of a CircuitModel.
Macro-node
Ordinary JavaScript behind typed inputs, outputs, effects, transaction, and trace.
AgentAuthoringContext
Host-compiled exact build vocabulary, circuits, demand, SDK providers, resources, commands, purpose, and digest passed to one Codex role.

Two different uses of “source”

Authority source defines the rule during training. Task source supplies observations during analysis. A task sentence cannot become authority merely because it contains an instruction, and an authority example cannot silently become a document fact.
