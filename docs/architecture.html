What a circuit is

A circuit has one business responsibility, not one algorithmic method. A scientific-consistency circuit can use typed query to select claims, EGraphLite to canonicalize compatible metrics, ConstraintKernel to compare quantities, a decision table to distinguish conflict from non-applicability, and a JavaScript macro-node to group a report's experiment arms. CircuitArchitecturePlan records that decomposition.

The source `.circuit.mjs` constructs a reusable CircuitModel. A CircuitInstance binds it to one snapshot, interpretation, and set of bindings. The concrete execution graph contains the nodes actually created by matches and subcircuits. These are three different objects; none is serialized as JSON.

SSA applies to published dataflow, not local JavaScript syntax. Semantic writes enter a transaction buffer and become visible only after type, evidence, provenance, layer, duplicate, and effect checks pass.

Concrete execution and assurance

Concrete execution is the business authority. Abstract interpretation can report that VIOLATED and UNKNOWN are both possible while exception coverage is open. Symbolic execution can find the exact five-year boundary and earns witnessed assurance only after concrete replay. ProofKernel can establish a small decision-table obligation. SynthesisEngine can propose a typed repair. These are selected per plan step and target, not applied indiscriminately to every circuit.

Environment isolation

One environment can contain a retention agent, a supplier-SLA agent, and an editorial-continuity agent. Each has immutable builds and a generated public context. A task for the supplier agent cannot discover the retention ontology. Its Codex workspace can write only task LongTextJS; the deterministic executor has no Codex capability.

Honest failure

Missing information is UNKNOWN; incompatible admitted support is CONFLICT; an absent constructor is BLOCKED_ONTOLOGY; a missing provider is BLOCKED_CAPABILITY; budget exhaustion is BLOCKED_RESOURCE; an exception or tool failure is ERROR_EXECUTION. None is formatted as compliance.

Normative contracts: DS000, DS008, DS009, DS012, DS013, and DS014.
