Three language roles, one semantic world

This page answers one question: how do executable JavaScript modules become an auditable semantic circuit without reducing JavaScript to data?

Why the circuit is dynamic

A circuit template does not pre-create every possible node. Matches bind variables and create concrete work; a stage may request a capability or run a subcircuit. The graph can grow during the snapshot, but each canonical instance is added once and committed values remain immutable.

Why the circuit is hierarchical

Declarative matching and decisions expose fine-grained nodes because the runtime understands their semantics. A graph algorithm or iterative solver stays a normal function and appears as an instrumented macro-node. This preserves both meaningful inspection and full JavaScript expressiveness.

What SSA means here

SSA governs published dataflow values, not local variables. A stage can update a local accumulator inside a loop; at commit it publishes one immutable result with one producer. If a step matters semantically, the author exposes it as a task, checkpoint, rule, or subcircuit.
