Deterministic execution and bounded assurance

The runtime evaluates one accepted AgentProject and one validated LongText snapshot. Codex has already left the process boundary.

Execution sequence

  1. Load the task pin, agent build, ontology, profile, circuits, and provider pins.
  2. Publish validated source/observation values into a new SemanticStore snapshot.
  3. Derive SemanticDemand and check concepts, roles, operations, evidence policy, and exact coverage.
  4. Plan the minimal authorized capability chain for the target.
  5. Create canonical root and per-binding CircuitInstances.
  6. Evaluate ready rules and stages; pure stage deltas may reuse content-addressed cache entries.
  7. Validate and commit semantic transactions; activate dependent nodes.
  8. Aggregate interpretation-aware results where the circuit requests it.
  9. Attach requested abstract, witnessed, local-proof, or generative assurance.
  10. Persist typed result, trace, and Markdown report.

Node lifecycle

CREATED → READY → RUNNING → PRODUCED → VALIDATED → COMMITTED
                  │                         │
                  ├── FAILED (no commit)   └── BLOCKED
                  └── CACHED (same typed value/provenance contract)

Technical node state is separate from business status. A successfully committed decision may be UNKNOWN; a failed stage produces no business verdict.

Multi-semantic example

A retention source says “between four and seven years,” and exception coverage is open. Abstract preflight can soundly retain SATISFIED, VIOLATED, and UNKNOWN as possible outcomes. Symbolic boundary generation may propose exactly five years and just above five years. Each generated case must become valid LongTextJS and replay concretely before it counts as witnessed. The final task still uses its concrete interval/coverage evidence.

Resource honesty

Node, instance, iteration, query, engine, and process budgets are explicit. Exhaustion is BLOCKED_RESOURCE, never an empty clean result. Current general parallel and cross-snapshot incrementality limits remain documented in serious issues.
