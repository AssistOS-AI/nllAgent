SemanticStore: one logical model

LongTextJS and CircuitJS share a typed attributed term graph. Physical indexes may change without changing agent code because circuits use a semantic query and transaction algebra.

Query, not storage traversal

const declarations = ctx.query(
  match(RetentionDeclaration(
    actor(controller),
    category(dataCategory),
    durationYears(duration)
  ))
);

The runtime can satisfy that pattern through concept and role indexes. Circuit code cannot depend on an internal array layout, mutate a stored term, or infer identity from an index key.

Identity and alternatives

A source mention, source entity, claim, event, and structurally canonical value have distinct policies. Alternatives share an immutable base and add context-specific facts. A result is robust only after explicit aggregation across all admitted interpretations; copying a proposed fact into the main context is forbidden.

Atomic semantic deltas

query stable epoch snapshot
  → stage builds candidate derivations/findings
  → validate types + layer + provenance + evidence + effects
  → commit all candidates
  OR discard the entire buffer on failure

If a verifier throws after the first of three candidate findings, none is visible. If two independent stages produce incompatible admitted values, the store retains conflict semantics rather than using publication order.

Coverage as data

Coverage is indexed by concept, exact scope, and evidence policy. Closing ExceptionEvidence in a policy's exception register does not close it in an external legal database or another document section. Query absence consults this typed coverage state.

Persistence and caches

Canonical LongTextJS, result, and trace modules are authoritative. Content-addressed caches are reconstructible. Cache identity includes code, ontology, inputs, context/interpretation, and policy dependencies; a hit never changes provenance.
