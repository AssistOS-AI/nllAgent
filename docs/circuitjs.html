CircuitJS: rules and real algorithms

CircuitJS combines typed declarative rules with full JavaScript stages inside one hierarchical dataflow program.

A declarative rule

const object = variable(ObjectEntity, 'object');

export default rule(
  'missing-retrieval',
  when(
    match(Leave(objectRole(object))),
    notExists(
      match(Retrieve(objectRole(object))),
      narrativeInterval,
      requireCoverage(Retrieve)
    )
  ),
  then(emit(ContinuityGap(objectRole(object))))
);

A procedural macro-node

export const timelineCheck = stage('timeline-cycles', async (ctx) => {
  const graph = new TemporalGraph();
  for (const event of ctx.store.instancesOf(Event)) graph.add(event);
  for (const cycle of graph.findCycles()) {
    const witness = await ctx.verify('cycle', () => replay(cycle));
    if (witness) ctx.emit(TimelineConflict(evidence(...cycle.claims)));
  }
});

The stage may use loops, classes, recursion, and promises. It cannot mutate source terms or indexes. ctx.derive and ctx.emit write to an atomic transaction; tools, models, tasks, checkpoints, and subcircuits are traced boundaries.

Choosing a form

Use a typed pattern/rule for relational conditions, a decision table for explicit policy combinations, a stage for algorithms, and a circuit for capability composition. Compact syntax is not a goal by itself.
