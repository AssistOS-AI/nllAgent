Command-line reference

The CLI keeps document work file-oriented. Structured artifacts are written inside the selected agent workspace as executable modules.

Audit

nllagent run --agent <name> --input <file.md> --output <report.md>
  [--foundation core|off] [--translator auto|achilles|codex|none]
  [--data-root <folder>]

Plan

nllagent plan --agent <name> --input <idea.md> --output <plan.md>
  [--realize-output <draft.md>] [--max-revisions <count>]
  [--foundation core|off] [--translator auto|achilles|codex|none]
  [--data-root <folder>]

Workspace and authoring

nllagent benchmark --agent <name>
nllagent learn --agent <name> --rules <folder>
nllagent agent init --agent <name> [--description <text>]
nllagent agent list
nllagent agent inspect --agent <name>
nllagent issue list --agent <name> [--status <status>]
nllagent feedback add --agent <name> --run <id> --type <type> --message <text>
nllagent model inspect

Parsing rules

Options use --name value, may occur once, and are command-scoped. Agent names are path-safe lowercase identifiers. The default data root is data/; the default foundation is core. Unknown compatibility options fail with exit 64.

Exit codes

0Completed report or plan.
2Configured blocking finding.
3–6Incompatible, incomplete, resource-blocked, or review-conflicted.
9Benchmark mismatch.
10Authoring failure.
64Usage or configuration.
70Unexpected runtime failure.

Normative contract: DS003.
