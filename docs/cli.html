Train and analyze are separate commands

The CLI preserves the two user journeys while enforcing their different permissions. The convenience binary dispatches the same contracts as the separately grantable train and analyze executables.

Compile a trained agent

node bin/nllagent-train.mjs train \
  --agent supplier-incident \
  --theory rules/service-agreement.md \
  --theory rules/notification-exceptions.md \
  --codex-bin codex \
  --data-root data

Success names the promoted immutable build. A candidate test, benchmark, review, context, or import failure returns nonzero and leaves current unchanged.

Analyze a document

node bin/nllagent-analyze.mjs analyze \
  --agent supplier-incident \
  --task incident-2026-0042 \
  --input evidence/incident-0042.md \
  --target findings \
  --output reports/incident-0042.md \
  --data-root data

The task identifier is unique. The selected build and source are pinned before Codex materialization. A semantic blocker can produce a preserved task/report and a distinct non-success result; a malformed materializer publishes no snapshot.

Inspect and replay

node bin/nllagent.mjs agent list --data-root data
node bin/nllagent.mjs agent inspect --agent supplier-incident --data-root data
node bin/nllagent.mjs task inspect --task incident-2026-0042 --data-root data
node bin/nllagent.mjs benchmark --agent supplier-incident --data-root data

Native authoring tools

node tools/nll.mjs source outline evidence/incident-0042.md
node tools/nll.mjs ontology inspect agent-build/ontologies/index.mjs
node tools/nll.mjs context inspect agent-build/context/agent-context.mjs
node tools/nll.mjs plan check agent-build/plans/incident.plan.mjs
node tools/nll.mjs circuit preflight agent-build/circuits/root.circuit.mjs
node tools/nll.mjs benchmark run agent-build/agent.mjs

Each tool loads real ESM values and writes a Markdown report when --report is supplied. It validates or explains code; method and business decisions remain in the plan and authority review.

Removed surfaces

There is no learn, run translator mode, --translator, direct-model selector, release-candidate publication command, JSON stdout contract, or Achilles configuration. Retraining is explicit train; document processing is explicit analyze.
