One source · one built-in rule · one verified warning

See the default consistency check run

This page gives a first-time reader the shortest complete path through nllAgent. It shows the source, the verbal rule, the actual CircuitJS author form, the command, and the CNL audit it produces.

1. Write an ordinary Markdown source

# Shift note

The north door is open at noon.
The north door is not open at noon.

No agent-specific rulebook mentions doors. The default foundation-core@1.1.0 pack is active for every ordinary audit unless the caller disables it.

2. Know the exact verbal rules being applied

The built-in logical circuit uses a deliberately narrow rule:

If two explicit controlled-English state assertions have the same subject, world, time frame, and explicit time, warn when the same predicate is both affirmed and denied. Also warn for a small declared set of mutually exclusive affirmative states.

Four other built-in circuits cover explicit before cycles, exact arithmetic, bounded physical quantities, and literal emotion/type consistency. They find nothing in this example. The selected editorial-demo release also runs ED-001 and ED-002, but neither matches. A report names every active circuit so an empty result is never mistaken for an absent check.

3. LongTextJS makes the source queryable

The compiler freezes the source, creates exact blocks, sentences, and anchors, then the foundation materializer recognizes two foundation.state-assertion@1 records. Each retains the sentence anchor, normalized subject and predicate, polarity, present/past frame, explicit time, source world, producer, and status. These are source assertions—not certificates that the door really exists or is open.

flowchart LR
  S["Exact Markdown"] --> P["document.sentence@1"]
  P --> A1["affirmed: door / open / noon"]
  P --> A2["denied: door / open / noon"]
  A1 --> Q["foundation state relation"]
  A2 --> Q

The compiler creates premises, not a verdict. The scan declares open-world coverage because it completely applies the documented grammar but does not pretend to extract every implicit fact, relation, action, emotion, or reported belief. Inspect runs/<id>/longtext.json only when you need that implementation-level evidence; the full data dictionary belongs in the LongTextJS reference.

4. CircuitJS expresses the reusable check

This is valid author-level DSL for the default logical circuit. The platform-owned implementation constructs the same graph as plain data in src/foundation/core-circuits.mjs; the runtime owns the operator algorithm, while the graph declares typed input, verification, and publication.

export default circuit({
  kind: 'CircuitJS',
  id: 'foundation.logical-consistency',
  version: '1.0.0',
  sourceRuleReferences: ['builtin:foundation-core@1#bounded-non-contradiction'],
  inputs: {
    assertions: {
      type: 'foundation.state-assertion@1',
      cardinality: 'many',
      statuses: ['extracted'],
      coverage: 'open-world',
      critical: true
    }
  },
  nodes: [{
    id: 'candidates',
    primitive: 'call',
    operator: 'foundation.state-conflicts@1',
    inputs: { assertions: binding('assertions') }
  }, {
    id: 'verified',
    primitive: 'verify',
    verifier: 'foundation.state-conflicts@1',
    inputs: { candidates: node('candidates') }
  }, {
    id: 'findings',
    primitive: 'emit',
    inputs: { verified: node('verified') }
  }],
  outputs: { findings: node('findings') }
});

The operator compares bounded contexts and constructs a witness containing both observation identities. The verifier independently rereads their types, context, polarity, source revision, and exact anchors. Only an accepted candidate reaches emit.

5. Run it and inspect the CNL audit

node bin/nllagent.mjs run \
  --agent editorial-demo \
  --input data/editorial-demo/examples/foundation/common-sense.md \
  --output /tmp/foundation-report.md \
  --translator none

cat /tmp/foundation-report.md

report.md is the deterministic Markdown view of the canonical CNL/Audit-1 result. For this exact source, it contains:

# CNL/Audit-1 audit report

- Agent: `editorial-demo`
- Release: `0.1.0`
- Foundation: `foundation-core@1.1.0`
- Terminal status: `reported`
- Compatibility: `compatible`
- Active circuits: `foundation.logical-consistency`,
  `foundation.temporal-consistency`, `foundation.arithmetic-consistency`,
  `foundation.physical-consistency`, `foundation.emotional-consistency`, `editorial.weak-phrase`,
  `editorial.perhaps-frequency`
- Blocked circuits: None

## Findings

### 1. FOUNDATION-LOGIC-001

- Verdict: `potential-logical-inconsistency`
- Circuit: `foundation.logical-consistency@1.0.0`
- Severity: `warning`
- Guarantee: `mechanically-certified`
- Subject / scope: `The north door` / `view:whole`
- Verifier: `foundation.state-conflicts@1` (`accept`)
- Certificate: `FoundationStateConflictCertificate`
- Rule basis: builtin:foundation-core@1#bounded-non-contradiction

> The north door is not open at noon.

The north door has incompatible state assertions at noon.

Remediation: Clarify the time, world, subject identity, or intended state.

Limitations: Only the documented controlled-English state form was evaluated.

The full report also records the immutable source digest, exact Unicode location, support anchors, and coverage. The important result is not merely that a warning appeared: compatibility allowed all seven circuits to run, the logical circuit constructed a bounded witness, its independent verifier accepted that witness, and the audit states the limitation of the claim. The run preserves the complete evidence in its artifact directory.

Different world model? The foundation can be disabled explicitly with --foundation off. That option and its consequences belong in the foundation reference, not in this first execution path.
