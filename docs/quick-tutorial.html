The source

A tiny literary fragment

Mara a intrat în cameră. De fapt, fereastra era deschisă.

Rule ED-001

Flag “de fapt” in a narrative paragraph.
Do not flag it in a dialogue paragraph that begins with an em dash or en dash.

Document side

LongTextJS gives the paragraph an address

The Markdown compiler does not decide that the rule was broken. It records a typed paragraph, its exact source range, its channel, and the fact that all paragraphs were structurally scanned.

Runtime boundary

A match is only a candidate

Operator output

Verifier output

accepted: true

The verifier uses the anchor to slice the frozen source and confirms the exact term at that location.

If the range were forged or the source no longer matched, verification would reject the candidate. emit never receives an unverified candidate.

Controlled output

The finding becomes one CNL audit observation

The runtime assembles the emitted finding, release identity, compatibility, coverage, limitation, and source evidence into canonical CNLAuditReport. Markdown is only its human-readable view.

De fapt

Now change only the context

Narration

De fapt, fereastra era deschisă.
1 candidate → 1 verified finding

Dialogue

— De fapt, fereastra era deschisă.
0 candidates → no finding for ED-001

The words did not change. LongTextJS recorded the paragraph prefix, and the released operator applied the dialogue exception before producing candidates. “No finding” here means only that ED-001 found no eligible occurrence; it is not a universal claim that the whole document is good.

The whole idea in three sentences

  1. LongTextJS describes one source instance: exact text, typed observations, addresses, coverage, and gaps.
  2. CircuitJS describes one reusable theory: accepted inputs, transformations, exceptions, verifier, and publication path.
  3. CNL is the controlled result: an audit of an existing source, or—through a separate planning circuit—a verified specification for a future source.
