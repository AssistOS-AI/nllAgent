Start · CLI · LongTextJS · CircuitJS

Audit one phrase end to end

You will run the included editorial agent, inspect its real materializer and circuit, and reimport the resulting modules. This tutorial does not teach ontology design or model translation.

1. The source

# Excerpt

Alice entered the room. In fact, the window was open.

2. The materializer

data/editorial-demo/longtext/editorial.materializer.mjs scans source text, creates an exact span for the whole phrase, and constructs a ground PhraseOccurrence term. It marks dialogue and code context explicitly. The source phrase is not yet a finding.

3. The circuit

data/editorial-demo/circuits/weak-phrase.circuit.mjs is a normal JavaScript stage. It queries typed occurrences, excludes dialogue/code, verifies the whole phrase against the anchored excerpt, and emits a typed Finding through its transaction.

4. Run it

node bin/nllagent.mjs run \
  --agent editorial-demo \
  --foundation off \
  --input data/editorial-demo/benchmark/public/weak-phrase/input.md \
  --output /tmp/editorial-report.md

5. Inspect the result

The reported run directory contains input.md, longtext/program.mjs, trace/run.trace.mjs, result.mjs, and report.md. Importing those modules reconstructs typed DSL values and reruns constructor validation; no hidden intermediate format is required.

6. Check the exceptions

node bin/nllagent.mjs benchmark --agent editorial-demo --foundation off

Ten cases cover clean prose, whole-word boundaries, dialogue, fenced code, paragraph-scoped frequency, and the positive examples.
