A green import is not a qualified semantic agent. Evaluation checks business outcome, exact evidence, interpretation, coverage, trace, mutations, and the ability of fresh coding roles to use the published skills.

Expected output remains independent from the circuit. If a comparator is inverted or open coverage is forged as closed, the unchanged case must fail. Message text alone is never the oracle.

Case matrix

Important rule families include conforming, violating, valid and incomplete exception, exact boundary, missing information, open/closed absence, ambiguity, incompatible claims, and ontology blocker cases. Recursive logic adds base, multi-hop, cycle, and duplicate cases. Controlled generation adds round-trip failure cases.

Performance interpretation

Reports separate Codex theory compilation, Codex source materialization, validation, and deterministic circuit execution. Replaying a frozen task does not call Codex. Measurements pin Node version, source size, term count, circuit work, and assurance profile; a single blended wall-clock number would obscure the architecture.
