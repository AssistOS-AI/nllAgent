Five design questions resolved by executable counterexamples

Run node experiments/architecture/run.mjs. Each program asserts the failure of a tempting alternative and records the selected contract.

QuestionObserved counterexampleDecision
Term identityStructural identity merges two people named Ana.Explicit source entities/events; structural immutable values and derivations.
Ontology behaviorA context-dependent exception needs store access.Behaviors are unary local operations; contextual logic is CircuitJS.
Alternative explosion18 binary readings produce 262,144 eager worlds.Shared factorized contexts, demand-lazy enumeration, proven-incompatibility pruning.
Model reuseOmitting ontology identity collides two semantic requests.Exact full-dependency key and accepted frozen artifact only.
CNL equivalenceFluent text can lose an exception or weaken MUST to MAY.Exact normalized equivalence of every critical and declared slot.
