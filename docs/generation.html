Controlled generation starts from meaning

A circuit emits a complete CNLFrame. A deterministic dialect renders it, parses the text again, and accepts it only when every critical slot survives.

const frame = cnlFrame(
  'obligation',
  actor('controller'),
  modality('MUST'),
  action('erase'),
  object('personal-data'),
  time('five-years-after-collection'),
  exception('documented-legal-duty')
);

const document = renderVerified(frame, normativeDialect);

The comparator checks frame kind, actor, modality, action, object, negation, time, condition, exception, authority, and every domain slot. Surface variation is acceptable only if parsing reconstructs the same frame.

Longer model-assisted text

A stage may build a semantic plan and call a writer. The result is a generated document tied to the plan and model artifact. It must be materialized as LongTextJS and audited again. A fluent draft is not a verified controlled-language artifact.

The included editorial agent implements deterministic plan generation and round-trip. Automated revision and reanalysis for arbitrary writers remain partial.
