Controlled repair starts from a typed frame

nllAgent never treats a fluent sentence as proof that a repair preserved policy. The circuit first constructs the intended semantic frame; a paired deterministic dialect renders and parses it; the comparator checks protected meaning.

Retention repair

A source clause permits ten years “for convenience,” while authority allows five years except for a documented legal obligation. Replacing ten with five alone can lose the conditional exception. The repair circuit instead constructs two frames:

obligation(
  actor(controller),
  action(erase),
  object(personalData),
  deadline(noLaterThan(yearsAfter(collection, 5)))
)

permission(
  actor(controller),
  action(retainLonger),
  object(personalData),
  condition(documentedLegalObligationRequiresLongerPeriod)
)

The renderer may produce a canonical two-sentence clause. Acceptance requires the parser to reconstruct both frames with the same actor, modality, action, object, deadline origin, quantification, and exception.

Bounded synthesis

SynthesisEngine searches only a typed finite grammar. Cost prefers preserving grounded values and making a minimal change. Every candidate is applied to a semantic copy and re-executed through the original rule circuit. A candidate that still violates the rule or invents an authority fact is rejected. Exhausted budget produces no repair, not the least-wrong sentence.

What is not verified generation

A long narrative drafted by Codex is an external workspace artifact. If used, it must become a new source revision, be materialized as LongTextJS, and pass the appropriate circuits. It does not receive CNL assurance and cannot write itself into the accepted agent or authority.

Language variants

An English and Romanian dialect may share ontology frames only when each has its own paired parser and both reconstruct the protected slots. Translation quality without round-trip evidence is not semantic equivalence.
