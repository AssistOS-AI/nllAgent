Executable semantic programming for natural language

NaturalLanguageLinterAgent

nllAgent turns authority and long documents into inspectable JavaScript programs. OntologyJS defines the vocabulary, LongTextJS describes the source world, CircuitJS computes judgments and controlled text, and one SemanticStore preserves identity, evidence, coverage, and provenance.

The decisive change: these languages are real ESM .mjs modules. Their constructors return opaque typed values. They are not configuration records, serialized syntax trees, or wrappers around a hidden data language.

What you can do

Use caseResult
Audit a Markdown documentA Markdown report plus reimportable LongTextJS, result, and trace modules.
Plan a documentA verified controlled-language plan produced from a typed semantic frame.
Build a specialized agentA multi-file project containing ontology, materializers, circuits, dialects, benchmarks, and tools.
Investigate uncertain meaningExplicit alternatives, gaps, unknown coverage, conflicts, and local blocked states.

Run the included project

node bin/nllagent.mjs benchmark --agent editorial-demo

node bin/nllagent.mjs run \
  --agent editorial-demo \
  --input data/editorial-demo/benchmark/public/weak-phrase/input.md \
  --output /tmp/editorial-report.md

node bin/nllagent.mjs plan \
  --agent editorial-demo \
  --input data/editorial-demo/examples/planning/idea.md \
  --output /tmp/editorial-plan.md
