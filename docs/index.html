Codex-authored, deterministically executed semantic programs

NaturalLanguageLinterAgent

nllAgent turns business rules into an immutable semantic analyzer and turns each audited document into a separate source-grounded program. Codex writes both programs under different skills and permissions; the result is computed by frozen JavaScript circuits, not by asking a model for a verdict.

Architectural boundary: OntologyJS, LongTextJS, and CircuitJS are internal ESM DSLs whose constructors create opaque typed values. There is no JSON semantic format, TypeScript layer, direct LLM runtime, or AchillesAgentLib dependency.

A concrete retention review

A privacy team trains privacy-retention from a retention standard and an exception policy. The generated ontology can represent retained data, duration, policy scope, and documented legal obligations. The generated circuit selects retention claims, compares their duration with the five-year limit, searches for an applicable exception only in a covered scope, and emits one of several explicit assessments.

Two operations, two authorities

theory Markdown
  → Codex + nll-train-agent
  → ontology + plan + profile + circuits + tests + benchmarks
  → independent review
  → immutable accepted agent build

task Markdown + one accepted build
  → Codex + nll-analyze-task
  → task-local LongTextJS with exact spans
  → deterministic circuit execution
  → typed result + trace + Markdown report

Training may change a candidate theory. Analysis may only describe one source using the selected theory. A task pins the exact build before generation begins, so retraining the same agent—or training another agent in the same environment—cannot change an existing result.

Executable evidence in this repository

  • Scientific consistency: metric compatibility, baselines, and conflicting quantities.
  • Narrative continuity: identity, temporal reachability, and missing transitions.
