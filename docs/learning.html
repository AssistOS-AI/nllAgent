Training means compiling theory

An nll agent is trained when Codex turns authority prose into a reviewed executable RulePack. No model weights are changed, and no custom runtime sends policy questions to an LLM.

The three skills

SkillReadsWritesCannot do
nll-train-agentTRAIN context, ordered theory, SDK and examplesCandidate ontology, plans, profile, circuits, tests, benchmarks, assemblyEdit accepted builds or invent benchmark oracles
nll-analyze-taskANALYZE context and one task sourceDependency-free task materializer and notesAdd a constructor, rule, finding, or theory fact
nll-review-and-repairREVIEW context, authority, candidate, diagnostics, tracesLayer-correct candidate/task repairs and handoffWeaken expected output or mutate a promoted build

Each SKILL.md links the underlying theory—term algebra, ontology boundaries, circuit methods, multi-semantic assurance, source grounding, category ownership, and mutation review—and runs code that validates its exact context.

What the context answers

For a supplier-incident agent, the context names the selected build; the Incident, Notice, BusinessHour, and ExcusedDelay constructors; actor/deadline/evidence roles; the incident-to-notice circuits; exact coverage needed to conclude no notice exists; available time/query/decision SDK providers; and commands/tests that must pass. Codex does not search unrelated agents or infer this contract from prose.

Candidate gates

  1. RuleAnalysis maps every authority clause and exact span.
  2. Ontology represents every source-observable premise and keeps findings derived.
  3. CircuitArchitecturePlan chooses methods per typed subproblem and pins reusable providers.
  4. MaterializationProfile is derived from circuit demand.
  5. Leaf and root circuits compile, declare effects, preserve four-valued truth, and emit evidence.
  6. Tests and semantic benchmarks cover boundaries, exceptions, unknown, conflict, and relevant mutants.
  7. A separate Codex review checks authority-to-trace fidelity.
  8. The host compiles the final ANALYZE context and atomically promotes a new immutable build.

Repair follows authority

If a LongText program cannot represent “service restoration window,” the ontology may need retraining. If the concept exists but the source span is wrong, only the task LongText changes. If the comparator is inverted, CircuitJS changes. If the expected result contradicts the written authority, independent rule review—not the circuit author—owns the oracle decision.

Why no Achilles or direct LLM layer

The difficult work is multi-file semantic programming: inspect code, reuse SDK APIs, run checkers, interpret traces, create counterexamples, and repair the correct layer. Codex already supplies that coding loop. Maintaining a second bespoke agent/model protocol would duplicate it while making the program/evidence boundary harder to audit.
